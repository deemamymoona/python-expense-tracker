# Python Expense Tracker

A menu-driven Python application that stores expense records in a CSV file and provides spending summaries.

## Overview

This project is a simple **Expense Tracker Application** developed in Python. It allows users to record daily expenses, store them in a CSV file, and view expense reports through a menu-driven interface.

Each expense record includes:

- Date
- Category
- Amount
- Note (optional)

The application also calculates the total amount spent and displays a category-wise spending summary.

This project was created as part of my **Day 4 Python Programming Internship Assignment** to practice file handling, CSV operations, exception handling, and functions.

---

## Features

- Add new expenses
- Store expenses in a CSV file
- View all expense records
- Calculate total spending
- Display category-wise spending summary
- Exception handling for invalid input
- Menu-driven interface
